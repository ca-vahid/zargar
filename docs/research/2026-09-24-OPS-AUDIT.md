## 1. Top findings

1. **The host is out of memory headroom.** 31.5 GB RAM, **0.6 GB free**, commit charge **72.5 / 78.2 GB**. The engine
   itself is small (252 MB). The memory goes to: WSL/Docker VM 4.0 GB, **15 `claude` processes 3.8 GB** (four started
   2026-09-22 and still alive), Cursor 2.0 GB, webview/Chrome/Edge ~3 GB, ChatGPT 0.8 GB, and at audit time **three
   ad-hoc Python jobs on the runtime box** (pytest chaos suite 557 MB, a Team2 pytest, `cartel_entry_grid` 1.1 GB).
   At the commit limit Windows fails allocations; the 2026-09-16 duplicate-engine incident started on a starved host.
2. **Options enrichment polls CBOE all night.** `OptionsService._enrich_loop` runs every 2 s with no market-hours gate
   (`options/service.py` ~L344-460). Today: **417 CBOE 429s** and **2,899 "enrich skipped"** lines, of which ~1,700 came
   between 00:00 and 06:30 PT, when delayed chains cannot change. The 06:00 PT hour (pre-open) had 109 429s, so the
   CBOE cooldown is already hot going into the open. Waste and a real SPOF risk (see section 6).
3. **Event-loop stalls: 167 today, 1,104 s in total, 16 over 10 s, worst 174.5 s** (14:47-14:50 PT). Attributed
   stall stacks: `httpx create_ssl_context` (a new AsyncClient per call: cartel `method_lab.warm`,
   `profitability_research._warm_baselines`, `preparation_readiness.load_session_context`, `signals.service._download_media`),
   asyncpg JSONB decode of large rows, and `options_cartel/history_cache.write_cache`. 84 stalls came in the 19:00 hour
   just after the restart.
4. **DB pool exhaustion at 08:28-08:33 PT (11:28 ET, market hours):** a stall run, then Alpaca stream drops (keepalive
   timeout, handshake timeouts x4), then `QueuePool limit of size 5 overflow 10 reached` with 7 ERRORs in 2 minutes:
   armer heartbeat failed, `team2_experiment_690` job FAILED, **daily loss monitor failed**, **Team2 trail gap
   (decision_inputs not journaled)**, equity snapshot failed, tip cohort recovery failed, and the sim fill lane dropped
   1000+ quotes. A 15-connection pool shared by five techniques, research jobs and the API is the choke point.
5. **Log rotation is broken since 2026-09-08.** `zargar-8420.log` is 15.9 MB while `.log.1..3` are 5 MB each and all
   dated 09-08 (RotatingFileHandler cannot rename a file another process holds open on Windows). 3,422 of today's
   4,304 WARNINGs are `persist_bars: dropped N non-bucket-aligned stub bar(s)` (`marketdata.py:401`) - noise at the
   wrong level that buries real warnings.
6. **Leftovers:** 159 git worktrees (139 are Codex review caches under `C:/Cursor/zargar-codex/.cache`, 88 detached),
   210 of 229 local branches and 200 of 217 remote branches already merged into origin/main, 33 test databases
   (615 MB), and 6 one-off scripts in `C:/ProgramData/Zargar`.

| Need | Primary | Fallback | Code |
|---|---|---|---|

| Option contract quotes | Alpaca OPRA (batch, 2 s) | the CBOE chain row (15-min delayed) | `options/service.py` |
| Option contract last/bars | Yahoo v8 with the unpadded OCC | none | |
| Chain snapshots for Flow/research | CBOE via `research/snapshots.py` | none | |
| Earnings/calendar | Yahoo quoteSummary | none | `calendar` |
| FX | Yahoo pairs | 1:1 with a warning | `positions.fx` |

Single points of failure:
1. **CBOE free endpoint** - no key, no SLA, rate limits the host today (417 x 429). Chains, strikes, greeks, OI and
   the delayed fallback for every option quote all hang on it. Tradier is wired but has no token. The cooldown is
   shared, so overnight enrichment can hold it hot into the open (`cboe_priority("position")` protects held contracts,
   but new EM/Team2/Cartel picks still need a chain).
2. **Yahoo** - unauthenticated, 429s every hour; it is the only source of session context, index history, FX and the
   Yahoo-side calendar, and the quote fallback when Alpaca drops (as at 08:29 today).
3. **Alpaca** - one key pair carries stock stream, OPRA and history. A lapsed subscription (08-26 precedent) degrades
   quotes to Yahoo, option quotes to 15-min-delayed CBOE (the risk gate then fails closed), and history to Yahoo.
4. **One asyncio loop + one 15-connection pool** for five techniques, research jobs and the API (finding 4).
