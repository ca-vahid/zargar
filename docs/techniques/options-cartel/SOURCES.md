The [TradingView US industry page](https://www.tradingview.com/markets/stocks-usa/sectorandindustry-industry/)
was opened directly. Its default Overview table exposes industry, market cap,
dividend yield, change, volume, sector and stock count. The observed ordering is
by market cap; it is not Sean's weekly/monthly performance ordering. The Performance
view was subsequently inspected in Chrome: separate `Perf % 1W` and `Perf % 1M`
column headers sort independently, with observed descending values after clicking.
Do not infer `weekRank` or `monthRank` from Overview row order.
The current table also does not prove historical point-in-time rank membership;
historical experiments still need source-dated rank snapshots.

row labels containing colons. Rechecking both label forms gives 129 data rows;
an independent read-only DOM count of table body rows also gives 129. All 129
rows have explicit percentage values in the 1W and 1M columns. The earlier
mismatch was a counting error, not evidence of missing provider rows. This
establishes coverage of the currently displayed industry table, not historical
membership, a supported automated feed or exact tie ordering.
