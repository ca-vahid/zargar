# C6 completion and parallel Practice launch

User authorized implementation, testing, merge, coordinated deployment and readiness for September 18 while away. Practice only. C2 remains sealed; no validation-period method outcomes were inspected or tuned.

## Implementation

Bars now carry `provider` independently of `source`. Alpaca stream/history and Yahoo poll/history stamp their own provider. A later Yahoo or unidentified exchange observation cannot replace an Alpaca observation. The same policy applies in the aggregator, batched flush, SQL upsert and Team2's private tape. Within a provider the established correction/zero-volume policy remains; an Alpaca replacement never borrows Yahoo volume. Content hashes include provider. Old unknown rows stay unknown until actually refetched.

`techniques.team2.canonical_provider` defaults off. With `alpaca` selected, Team2 planning, warm-up, pre-market, live decisions and research exclude other providers. New plans require twelve valid canonical warm-up sessions and stamp `inputProvider`. Warm-up is saved in a content-addressed immutable snapshot shared across books. Live/restore/replay load those exact rows. Missing/corrupt snapshots fail rather than substituting another seed. Decision journals record the current input hash and indicator state; later corrections remain revisions, not retroactive orders.

`python -m zargar.tools.team2_c6 --apply --migrate --end 2026-09-17 --out <runtime-log-path>` uses the existing runtime configuration without starting another engine. It archives and verifies SPY/QQQ/IWM before-images, fetches Alpaca SIP extended-hours data directly (no Yahoo fallback), applies provider precedence, records coverage and changed-row examples, then verifies snapshot/indicator identity. Historical plan decisions are retained. Additive schema uses the normal `db.create_all`/`_ensure_columns_sync` path.

The agreed sampled experiment thresholds are checked by engine jobs every thirty minutes from 09:30 through 16:00 ET, independent of agent availability. Sizing uses $800 and C1 $1,000 sampled peak-to-trough drawdown. State retains starting equity/high-water mark across days/restarts. Cash includes fees; held options use fresh bids. Missing marks are unknown and do not update the high-water mark. Breach persists a book pause; it does not change sizing or resume automatically. Protective exits and existing risk limits remain active. These are sampled review thresholds, not guaranteed loss caps.

Isolation now precedes startup and the scheduler is disabled only in that manual-driver fixture. This is a reproduced contamination path, not an attribution of every earlier intermittent failure.
